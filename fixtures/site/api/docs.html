API pública de catálogo — documentación

API de solo lectura, pública y sin autenticación, publicada por el propietario de este sitio de pruebas. Uso permitido para fines académicos con un máximo de 1 solicitud por segundo.

GET /api/v1/products?page={n}

Devuelve data (lista de productos), meta (página y total) y links.next (URL de la página siguiente o null).

Especificación: OpenAPI (JSON)
